Roadmap

  1. Phase 1: static site. Container, Deployment, Service, Ingress.
  2. Phase 2: config. Change the title via a ConfigMap, no rebuild.
  3. Phase 3: API. Small backend that reports its Pod name.
  4. Phase 4: database. StatefulSet, PersistentVolume, Secret.
  5. Phase 5: GitOps. Git is the source of truth, the cluster follows.
  6. Phase 6: observability. Prometheus and Grafana.
  7. Phase 7: my domain. DNS and TLS certificates.
